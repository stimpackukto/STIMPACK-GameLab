1. 개인정보 처리 목적 및 항목

STIMPACK GAME LAB(이하 ‘운영자’)은 STIMPACK 장기(이하 ‘서비스’)의 Google 계정 인증, 게임 설정과 승패의 기기 내 관리, 완료 대국 기보의 분석 및 AI 개선을 위해 다음 정보를 처리합니다.

구분처리 항목목적 및 보관 위치
Google 로그인(선택)Google 계정 고유 식별자, 표시 이름, 이메일, 프로필 사진 URL, 가명 계정 ID계정 확인 및 화면 표시. 이름·이메일·프로필 정보와 가명 ID는 기기에 보관하며 PC의 장기 전용 서버 세션에는 계정 식별자와 동의 버전을 처리합니다. Android 앱의 로그인 유지에는 가명 계정 ID와 해시 처리한 무작위 기기 인증 토큰, 접속·만료시각을 DB에 저장합니다.
기기 내 게임 설정AI 종류, 대국시간, 누적 승·패, 동의 상태, 기보 전송 건수계정 사용자별 게임 편의를 위해 브라우저의 localStorage에 저장. 서버에서 기기 간 전적 동기화는 제공하지 않음
서버 학습용 기보착수 좌표·차례·한 수 쉼, 승패·종료 사유, AI 종류, 시간 설정, 기물 배치, 대국 ID, 계정 이용자의 가명 ID장기 AI 분석 및 개선. 이용자 동의에 따라 서버 기보 DB에 보관. 게스트 기보는 계정 식별자와 연결하지 않음
서비스 접속IP 주소, 요청 시각, 브라우저·기기 기술 정보 등 접속 정보웹서버 및 브라우저·호스팅 환경에서 네트워크 운영, 장애 분석, 보안 목적으로 로그가 처리될 수 있음

앱 자체는 게임 제공을 위해 카메라·마이크·주소록·문자메시지·정밀 위치 또는 기기 전체 저장공간 접근 권한을 요청하도록 설계하지 않았습니다.

2. 장기 전용 Google 계정 인증

계정 연결은 STIMPACK 장기 전용 Google 로그인 화면에서 진행하며, STIMPACK GAME LAB 홈페이지의 일반 로그인 세션과 분리되어 있습니다. Google이 발급한 ID 토큰은 서버에서 서명·대상·유효기간·일회용 검증값을 검사하는 용도로 사용됩니다.

  • 운영자는 Google 계정 비밀번호를 수집하지 않으며 Google ID 토큰을 게임의 기기 저장소에 보관하지 않습니다.
  • 장기 인증 세션 쿠키에는 HttpOnly 및 Secure 등의 보호 속성을 적용합니다.
  • 이름·이메일·프로필 URL·가명 식별자는 사용자의 브라우저 저장소에 보관됩니다.
  • 계정 연결 해제 시 계정 표시정보와 동의 상태는 초기화되지만, 해당 계정에 연결된 기기 내 전적·설정 데이터는 남을 수 있습니다. 완전한 기기 기록 정리는 아래의 계정·데이터 삭제 페이지를 사용해 주세요.

3. 기보 전송과 AI 학습 동의

계정 이용자

AI 학습용 기보 전송 동의는 Google 계정 연결 전에 명시적으로 받습니다. 동의한 계정 이용자의 완료 대국 기보는 AI 분석·개선 목적으로 서버에 자동 전송됩니다. 동의를 철회하면 계정 연결을 해제하고 향후 자동 전송을 중단합니다.

게스트 이용자

게스트는 Google 로그인 없이 플레이할 수 있으며 승패와 게임 설정을 기기에 누적 저장하지 않고 새 대국을 기본 상태로 시작합니다. 대국 종료 후 기보 전송 버튼을 직접 선택한 경우에만 해당 완료 기보를 익명으로 서버에 전송하며, 서버가 성공을 확인한 뒤 다음 대국을 시작하도록 구성되어 있습니다. 기보 전송을 원하지 않을 때에는 게임 이용을 종료할 수 있습니다.

계정 연결 기보에는 Google 계정 식별자 원문 대신 서버 전용 비밀키로 생성한 가명 ID가 연결됩니다. 기보 DB에는 이용자의 이름, 이메일 또는 Google 인증 토큰을 저장하지 않도록 설계했습니다. 기보를 판매하거나 광고 개인화 목적으로 이용하지 않습니다.

4. 개인정보 보유기간 및 파기

  • 기기 설정: Google 연결 표시정보와 전적·게임 설정은 기기 내 브라우저 저장소(localStorage)에 보관됩니다. 연결 해제 시 표시정보와 동의 상태는 초기화되지만 계정별 전적·설정은 남을 수 있습니다. 모두 삭제하려면 아래 데이터 삭제 페이지 또는 해당 사이트 데이터 초기화를 이용해 주세요. 기기 간 자동 동기화는 제공하지 않습니다.
  • 로그인 세션: PC 웹은 마지막 장기 서버 요청 이후 30분간 활동이 없으면 인증이 만료됩니다. Android TWA 앱은 로그아웃 전까지 연결을 유지하기 위해 기기의 보안 쿠키와 서버 DB의 해시 토큰을 사용하며, 365일 동안 사용하지 않으면 만료됩니다. 이용 중에는 만료일이 갱신될 수 있습니다. 로그아웃 시 서버 토큰을 삭제하며, 브라우저 데이터 삭제나 보안상 무효화 시 재로그인이 필요합니다. TWA는 기기 브라우저를 이용하므로 앱과 동일 브라우저의 사이트 데이터가 공유될 수 있습니다.
  • 서버 기보: AI 학습용 기보의 보유 기준은 수집일부터 365일입니다. 기간 경과 기록은 서버의 정기 삭제 작업으로 파기하도록 설계했습니다. 실제 운영 서버의 삭제 작업 설정과 정상 수행 여부는 운영자가 확인해야 하며, 삭제 요청을 받은 연결 계정의 기보는 별도 삭제 API로 처리합니다.
  • 접속 기록: 웹서버·호스팅 운영 및 보안 로그의 보관 기준에 따라 별도로 처리될 수 있습니다.

중요: Google 계정 연결 해제·동의 철회만으로 이미 제출한 서버 기보 또는 남아 있는 계정별 기기 전적이 모두 삭제되지는 않습니다. 연결된 기보와 기기 기록을 삭제하려면 아래 계정 및 데이터 삭제 기능을 이용해 주세요.

5. 외부 서비스 및 정보 제공

Google 계정 로그인에 Google Identity Services를 사용하며, Google 로그인 과정에서 계정 선택과 인증에 필요한 정보가 Google 서비스와 교환됩니다. Android 앱은 브라우저 기반 Trusted Web Activity(TWA) 방식으로 게임을 실행합니다.

웹게임은 Phaser 라이브러리를 기본적으로 자체 호스팅하지만, 파일 로딩에 실패한 경우 cdnjs(Cloudflare)에서 라이브러리를 요청할 수 있습니다. 이 경우 IP 주소·요청 정보 등 통상적인 네트워크 정보가 해당 제공자에게 전달될 수 있습니다. Android 앱은 브라우저 기반 Trusted Web Activity(TWA)로 웹게임을 실행하므로 이용 브라우저의 개인정보 처리 정책도 적용됩니다.

수집된 AI 학습용 기보는 광고 맞춤화나 판매 목적으로 사용하도록 설계하지 않았습니다. 법령에 따른 의무가 있는 경우 관계 법령에 따라 처리할 수 있습니다. 새로운 제3자 제공 또는 처리 방식이 도입되면 본 방침을 변경해 안내합니다.

Google 개인정보처리방침: https://policies.google.com/privacy

6. 개인정보 안전성 확보 조치

서비스는 HTTPS 통신, Google ID 토큰의 서버측 검증, HttpOnly·Secure 인증 쿠키, 가명 계정 ID 및 API 요청 출처 확인 등 기술적 조치를 적용합니다. Google 비밀번호·ID 토큰을 게임의 장기 기기 저장소에 기록하지 않습니다. 전송된 기록의 무단 접근이나 위·변조 위험을 줄이도록 서버 접근 권한과 로그를 점검합니다.

7. 이용자의 권리 및 계정·데이터 삭제

이용자는 장기 게임의 계정 관리에서 기보 전송 동의를 철회하고 장기 전용 Google 연결을 해제할 수 있습니다. 이미 수집된 기보에 대한 삭제는 별도의 요청이 필요합니다. 동일한 Google 계정으로 장기 인증을 완료한 뒤 아래 페이지에서 계정에 연결된 서버 기보 및 현재 기기의 게임 기록을 삭제할 수 있습니다. 이 절차는 Google 계정 자체를 삭제하지 않습니다.

게스트 기보는 계정·이메일을 연결하지 않고 수집하므로 특정 이용자의 기보를 개별적으로 찾아 삭제하는 데 제한이 있을 수 있습니다. 요청에 관한 문의는 아래 안내를 참고해 주세요.

계정 및 데이터 삭제 안내장기 게임으로 돌아가기

장기 계정 연결 삭제는 사용자의 Google 계정 자체를 삭제하는 기능이 아닙니다. Google 계정 자체의 삭제는 Google에서 별도로 진행합니다.
